# Mon énergie

Une petite app douce pour noter son énergie chaque jour (4 états : 😢 Pas d’énergie, 😊 Bien, 😎 Au top, 🫨 Submergé), la voir dans un calendrier et repérer ses cycles.

- Aucune donnée ne quitte le téléphone : pas de compte, pas de serveur, pas de suivi.
- Fonctionne hors ligne une fois installée.
- 3 boutons : Noter, Calendrier, Rappel.

👉 **Ouvrir l'app : https://funny-beaver.github.io/energie/**

## Installer sur iPhone

1. Ouvrir https://funny-beaver.github.io/energie/ dans **Safari**.
2. Toucher **Partager**, puis **Sur l'écran d'accueil**.
3. Ouvrir l'app depuis son icône (pas depuis Safari) : c'est là que les données sont gardées.

## Rappel quotidien

Dans l'app **Raccourcis** : Automatisation → Nouvelle → **Heure de la journée** → choisir l'heure, Tous les jours, Exécuter immédiatement → action **Ouvrir les URL** avec `webapp://` (iOS 16.4 ou plus).

## Sauvegarde

Bouton **Sauvegarder** dans l'onglet Rappel : enregistre une copie (fichier .json), par exemple dans Fichiers. **Restaurer** la recharge.
